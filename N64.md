# Battle for Wesnoth on the Nintendo 64

This branch builds the Wesnoth engine itself (unmodified game logic, WML,
Lua, GUI2, AI) for the Nintendo 64 with an Expansion Pak, running from a
**SummerCart64** flashcart. Online play is not available.

## What the console runs on

| Need | How the port meets it |
|---|---|
| 8 MiB RAM, engine code ~11 MiB | Code and read-only data are demand-paged from the cartridge into a pool of RAM frames (`src/n64/pager`). |
| Engine heap of 15+ MiB | The heap is paged too, swapping to the SummerCart64's SDRAM above the ROM image (`n64_vheap.cpp`). |
| 630 MiB of game data | The SD card holds an unmodified copy of the data tree; user data (saves, preferences) also lives on the card. |
| SDL 2, SDL_image, SDL_mixer | Real upstream libraries with an N64 platform layer (`src/n64/sdl2`): RDP render driver, video/input, audio, timers. |
| Text and vector drawing | Real cairo, FreeType and HarfBuzz, plus the Pango calls Wesnoth makes (`src/n64/pango`). |
| Display | The engine draws a 640x480 window, shown at 640x240 progressive (the console's highest non-interlaced mode). |

## Building

1. Toolchain: build GCC + libdragon with Pak's `tools/build_n64_toolchain.sh`
   and `tools/build_libdragon.sh` (default prefix `/opt/n64_toolchain`), then
   fix libgcc's unwinder for 64-bit kernel addressing:

       tools/patch-n64-libgcc.sh

2. Third-party sources (SDL, SDL_image, SDL_mixer, FreeType, HarfBuzz,
   pixman, cairo):

       tools/fetch-n64-deps.sh            # into /opt/n64-src

3. Configure and build the ROM:

       cmake -S . -B build-n64 -DCMAKE_TOOLCHAIN_FILE=cmake/toolchains/n64-libdragon.cmake
       cmake --build build-n64 --target wesnoth_n64 -j$(nproc)

   The ROM is `build-n64/wesnoth_n64.z64`.

## SD card

Format the card FAT32 (or exFAT) and copy the data tree:

    tools/n64-make-sd.sh dir /path/to/mounted/card

This creates `wesnoth/` (data, images, sounds, fonts) and `wesnoth-userdata/`.
Put `wesnoth_n64.z64` on the card as usual for the SummerCart64 and start it.

## Controls

| Controller | Game |
|---|---|
| Analog stick | mouse pointer |
| A / B | left / right click |
| Z | Return |
| Start | Escape (menu, cancel) |
| D-pad | scroll the map (arrow keys) |
| C-up / C-down | mouse wheel |
| C-left / C-right | next unit (n) / end unit's move (space) |
| L / R (held) | Shift / Ctrl |

## Testing in an emulator

ares with SummerCart64 emulation (registers, writable SDRAM, SD card):

    tools/build-ares-sc64.sh /path/to/Pak            # builds ares + tools/ares-sc64.patch
    tools/n64-make-sd.sh image sd.img                 # FAT32 image of the data tree
    SC64_SD_IMAGE=sd.img tools/n64-run-ares.sh build-n64/wesnoth_n64.z64 shot.png 120

`wesnoth_n64_sdltest` is a small ROM that checks the SDL port (renderer,
textures, blending, images, cursor, timers, input).
